# Jantar Mantar News Evidence Backend

This backend is scoped specifically to news/events associated with Jantar Mantar, New Delhi.

Endpoints:
- GET /api/health
- GET /api/news
- GET /api/history
- POST /api/analyze

The initial evidence database contains curated Jantar Mantar reports for the CJP/NEET protests in June-July 2026 and the separately reported October 10, 2026 CJP protest plan.

This is a seeded evidence prototype. It is not yet an automatic all-news internet crawler.
